# MCM2026 Repository

This repository contains all materials generated by our team during MCM2026.

# 美赛 (MCM/ICM) 2026 建模工作流与竞赛新规

## 1. 2026 特别注意事项 (New Requirements)

*   **AI 使用政策 (Use of Large Language Models & AI)**: 
    *   **允许使用**: 可以使用生成式 AI (ChatGPT, Claude, Gemini, Copilot 等) 进行编码、调试、翻译或文本润色。
    *   **强制声明**: 必须在论文末尾（参考文献 Reference 之前）包含一个新的章节 **"Report on Use of AI"**。
    *   **声明内容**: 必须明确列出使用的 AI 工具名称、使用的具体场景（如：代码生成、思路启发、段落润色）以及未直接引用的生成内容。**未能妥善声明可能导致取消资格 (Disqualification)。**
*   **页数限制 (Page Limit)**: 
    *   论文总长度不能超过 **25页**。
    *   这包含：摘要页 (Summary Sheet)、正文、参考文献、AI 使用报告和附录 (Appendices)。
    *   **注意**: 代码通常不计入正文，但如果放入 AI 报告或附录，必须包含在 25 页内。

## 2. 整体流程 (Workflow)

1.  **选题与破题 (Topic Selection & Analysis)**
    *   **起步 (Hours 0-6)**: 快速浏览所有题目 (A-F 题)。
    *   **定题**: 确定选题后，立即建立 Git 分支或文件夹，明确分工。

2.  **数据收集与预处理 (Data)**
    *   **来源**: 优先使用官方权威数据。
    *   **记录**: *关键*：记录所有数据的来源 URL 和访问时间，为论文引用 (References) 做准备。
    *   **数据文件**: 竞赛可能要求提交只要的数据文件 (e.g., CSV, Excel)，注意保持整理。

3.  **模型构建 (Modeling)**
    *   **Baseline**: 先跑通简单模型。
    *   **假设 (Assumptions)**: 明确列出假设条件。
    *   **方法**: 微分方程、优化模型、机器学习、评价模型等。

4.  **模型求解与验证 (Solving & Validation)**
    *   **工具**: Python (NumPy, SciPy, Pandas, Scikit-learn)。
    *   **灵敏度分析 (Sensitivity Analysis)**: 必做！改变关键参数，观察模型输出的稳定性。

5.  **论文写作 (Writing)**
    *   **结构**: Summary Sheet -> Table of Contents -> Introduction -> Assumptions -> Models -> Solution -> Sensitivity Analysis -> Strengths/Weaknesses -> Conclusion -> **Report on Use of AI** -> References -> Appendices.
    *   **摘要 (Summary)**: 评审的核心依据，需包含：解决什么问题、用了什么方法、得到了什么具体结果。

## 3. Jupyter 使用建议

*   **代码注释**: 利用 Markdown 单元格解释代码意图，方便转写到论文中。
*   **可视化 (Visualization)**: 
    *   图表需包含：标题 (Title)、轴标签 (Axis Labels)、图例 (Legend)。
    *   配色尽量符合学术标准。

## 4. 提交前检查 (Checklist)

*   [ ] **AI 报告**: 是否已添加 "Report on Use of AI" 章节？
*   [ ] **页数检查**: 总页数（含附录）是否在 25 页以内？
*   [ ] **控制号**: 每一页页眉是否包含 Team Control Number？
*   [ ] **匿名性**: 确保论文中**没有**出现学校名称或队员姓名。
*   [ ] **文件格式**: 提交的是 Adobe PDF 格式吗？
*   [ ] **摘要页**: Summary Sheet 必须是文件的第一页。
